Planilhas de cenários de teste

Ajustador de Cenários

Envie a planilha: todas as células mescladas são desfeitas e o dado é repetido em cada célula, para que toda linha de teste fique completa. O arquivo ajustado é gerado para download e o original não é alterado.

  • Nada é perdido. Estilos, comentários, imagens, gráficos, filtros e macros ficam como estavam; só as mesclagens mudam.
  • Valores escondidos dentro de uma mesclagem (gravados por outros sistemas) são mantidos, nunca sobrescritos.
  • Linhas que já eram repetidas no arquivo original não são apagadas; aparecem como atenção para você revisar.
  • Abas com fórmulas, comentários, links, imagens, validação ou formatação condicional não têm linhas removidas, para não quebrar referências.
  • Conferência final: o arquivo gerado é relido e comparado com o original antes de liberar o download.
Tudo roda no seu navegador. A planilha não é enviada para nenhum servidor.
